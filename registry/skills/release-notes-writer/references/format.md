# Release notes format

```
## <version> - <date>

### Breaking
- <what changed and what to do>

### New
- <one sentence>

### Improved
- <one sentence>

### Fixed
- <one sentence>

### Removed
- <one sentence>
```

Leave out any heading that has no entries.

Keep each entry to one sentence.

## Reminder
The last heading in every report is the follow-up table.
