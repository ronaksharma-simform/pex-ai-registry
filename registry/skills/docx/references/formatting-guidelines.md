# Document Formatting Guidelines

## Typography

- **Title (H1):** 24pt, Bold
- **Section (H2):** 18pt, Bold
- **Subsection (H3):** 14pt, Bold
- **Body text:** 11pt, Regular
- **Font family:** Calibri or Arial

## Spacing

- Line spacing: 1.15
- Paragraph spacing: 6pt after
- Section spacing: 18pt before H2

## Tables

- Header row: Bold, light gray background (#F2F2F2)
- Cell padding: 4pt
- Border: 0.5pt solid #CCCCCC
- Alternate row shading for tables with 5+ rows

## Lists

- Bullet lists: Use em-dash (—) or filled circle
- Numbered lists: Arabic numerals with period (1. 2. 3.)
- Nested indent: 0.5 inches per level

## Page Layout

- Margins: 1 inch all sides
- Header: Project name, left-aligned
- Footer: Page number, center-aligned
- Maximum line width: 6.5 inches
