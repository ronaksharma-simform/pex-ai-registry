# Technology Option Comparison Template

## Scoring Criteria

Each option is scored 1-5 on these dimensions:

| Criteria          | Weight | Description                                    |
| ----------------- | ------ | ---------------------------------------------- |
| Fit-for-purpose   | 30%    | How well does it meet functional requirements? |
| Scalability       | 20%    | Can it handle projected growth?                |
| Team expertise    | 15%    | Does the team have experience?                 |
| Community/Support | 10%    | Documentation, community size, vendor support  |
| Cost              | 15%    | Licensing, infrastructure, maintenance costs   |
| Time-to-market    | 10%    | How quickly can we deliver?                    |

## Option Template

### Option {N}: {Technology Stack}

- **Overview:** Brief description
- **Strengths:** Key advantages
- **Weaknesses:** Key disadvantages
- **Risk factors:** What could go wrong
- **Score:** Weighted total out of 5.0
